# 行驿 · Wander Bound｜把美好装订成册

你去看世界，剩下的交给我。Go See the World. Leave the Rest to Me.

## 一本属于你的旅行手帐

我们拍下越来越多的旅行照片，却很少把它们重新翻出来。行驿想为记忆找回一个依托：让照片、时间、地点和当时写下的话，成为一本多年后仍愿意翻开的手帐。

这本手帐的内容来自你的旅程。照片提供证据，行程提供脉络，AI 负责挑选、编排与绘制有出处的装饰素材。它不会把没有证据的航班、酒店或到访地点补成“完整故事”。你编辑过的页面也会受到保护。

## 好的 Agent 像管家

出发前，你可以只说：“从重庆出发，玩 3 天。”行驿先查真实交通、住宿、地点与路线，再计算逐日时间线。缺少会改变路线决定的信息时，它才问；问题附带可点击的选项和“其他”。答案保存后，规划继续。最后的路线由你确认。

我们把这称为 **无感、在场、有分寸**。少打扰来自主动完成准备；在场意味着关键数据可查证；有分寸意味着系统可以提出和调整草案，而你始终拥有决定权。拿不到的数据，行驿会说“未核实”。

## 旧相册也能开启一场旅行

经你授权，iOS 先在设备上查看照片的时间和位置，你选择候选旅程后才上传相关原图到私有节点。系统结合 EXIF、数值画质与本机视觉标签，生成历史旅程的证据草稿。票面目的地不直接算作到访，列车线路全程不直接算作你的上下车站；你可以修正、撤销并确认。

精选照片随后进入手帐。AI 编排逐页照片、短日记与明信片文字；Spark 上的 Qwen-Image 2.1 从空白画布生成贴纸、邮票和插画，MiniMax H3 将精选照片做成短镜头。素材生成依据已确认地点和照片文字标签，不把用户照片放进贴纸生成链路。创意照片重绘使用独立的图像编辑工作流。

## 一台安静工作的 DGX Spark

照片原件、私有 EXIF、精确位置和本地媒体生成留在私有环境。对外展示图像重新编码去掉 EXIF；外部 StepFun 处理规划需求和筛选后的手帐文字标签，原图字节不进入它的编排请求。

单颗 GB10 的 128 GB 统一内存需要精细安排。模型控制器检查任务、引擎队列、内存与压力；空闲模型会释放，视频任务需要资源时本地对话模型可以让位。手帐素材和短片落盘排队，默认夜间工作，并在机器连续空闲后才领取。忙时继续等待，重启后从队列恢复。你看到的是可修改的结果，计算发生在幕后。
